What this does

This page helps you prepare a prompt, which is the request you type into an AI tool. It does not send your prompt to an AI, and it does not do the task for you. When you're ready, you can copy the prompt into an AI tool yourself.

Before you start: keep it private

Use made-up details or placeholders like [NAME], [ADDRESS], or [ACCOUNT #] instead of real private information. Don't type real names, account numbers, health details, or anyone else's personal information.
